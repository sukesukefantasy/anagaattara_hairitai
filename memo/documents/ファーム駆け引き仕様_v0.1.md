正: [プロジェクト定義ドキュメント_v8.5.md](プロジェクト定義ドキュメント_v8.5.md) §5・§9。実装の正は `lib/system/farm_role_profile.dart`・`lib/system/automation_ability_catalog.dart`・`lib/component/game_stage/building/automation/`。

## 解禁条件・入口（統合 v0.3 — 3種装置）

| 項目 | 内容 |
| :--- | :--- |
| **対象** | 調査対象星のみ（`outdoor_1`〜`outdoor_4` 等。`outdoor_0`・True 系は除外） |
| **HUD ショップ** | 対象星にいる間、右上ボタンから常時 [`AutomationShopWindow`](lib/UI/windows/automation_shop_window.dart)（**収穫／整備／防衛／共通** の4タブ） |
| **初回案内** | 対象星**初回入場**で青メッセージ → **主軸3択**（ショップ相性・ROI 用）→ 装置設置の案内 |
| **3種装置** | 設置アイテム: `自動収穫ツール`（nozzle）/ `自動整備ツール`（valve）/ `自動防衛ツール`（igniter）。ロケット部品（`ノズル`等）と**名前で区別** |
| **設置上限** | **種別ごと1台**（計最大3台）。対象星（outdoor_1〜4）を移動しても **同じ3台が現ステージへ引き継がれる**（X座標維持・地面Yに再スナップ） |
| **装置入手** | **警戒ティア上昇**で [`AlertHunterEnemy`](lib/component/enemy/alert_hunter_enemy.dart) 出現。**撃破のたび**未付与種を1つバッグ付与（順: 収穫→整備→防衛）。3種揃い後は代替報酬 |
| **開放 vs 強化** | **ショップ** = 能力の**開放**（`automationUnlocks`）。**装置インタラクト** = 開放済み能力の**強化**（`automationUpgradeLevels`） |
| **強化上限** | 調査ステージ tier ごとに +4 Lv（`outdoor_1`=上限4 … `outdoor_4`=16、philosophy=20）。絶対最大 Lv24。UI はショップ同様の状態チップ |
| **整備 UI** | [`AutomationToolWindow`](lib/UI/windows/automation_tool_window.dart): 強化ツリー・手動サイクル・燃料補給・収穫ストレージ回収 |

旧 **単一自動化キット** セーブは **整備ツール1台** として `migrateLegacyAutomationKitIfNeeded()` で復元。`automationKitStage` は整備の稼働段階（C-2 契約と連動）。

意志力累計10（旧 §6.1）は **HUD解禁には使わない**（微細ログ用に残す場合あり）。

## ローグとの対称

| ルート | 主軸（1つだけ） |
| :--- | :--- |
| ローグ | 攻撃特化 / 防御特化 / 回避特化 |
| ファーム | **収穫特化** / **防衛特化** / **整備特化** |

## ショップ UI 状態（2026 実装）

[`buildAutomationShopEntries`](lib/system/automation_shop_entry.dart) が dry-run し、[`AutomationShopWindow`](lib/UI/windows/automation_shop_window.dart) で各行を表示する。

| 状態 | 意味 |
| :--- | :--- |
| **購入済** | 解放済み・ボタン無効 |
| **購入可** | 前提・資源ともに充足 |
| **未解放** | 前段未購入・終盤条件未達 |
| **不足** | 前提 OK だがカーゴ／通貨／意志力／核が足りない |

購入成功時は `automationUnlocks[id]=true`（数値強化は装置 UI）。ヘッダに **母星人間性**（0–100）を情報表示。

## ゲームプレイ概要（装置別）

| 装置 | 稼働内容 | 強化軸（例） |

## 介入（手動稼働）

- **整備**の手動サイクル後 **12秒** の介入ウィンドウ（`openFarmInterventionWindow`）。
- 自動サイクル中に低確率（8〜22%）で:
  - **2倍サイクル**（次回1回）
  - または主軸に応じた即時報酬（収穫=通貨+、整備=回復）
- 収穫主軸は介入成功率がやや高い。

## 燃料（3種共通・ランク制）

プレイ上は**燃料缶／凝固ブロック**比喩。設定上は**行動の残滓／意志を整備装置で圧縮した駆動熱**（石油ではない）。

| ランク | UI 名称 | 作り方 | タンク効率 | 相性 |
| :--- | :--- | :--- | :--- | :--- |
| **R0** | 粗製燃料 | 整備 UI：残滓1→缶1 | 低 | — |
| **R1** | 生命馏分 | 整備 UI：生命残滓2（最多） | 中 | 防衛◎ |
| **R2** | 歴史胶质 | 整備 UI：歴史残滓2（最多） | 中 | 収穫◎ |
| **R3** | 無機基油 | 整備 UI：無機残滓2（最多） | 中 | 整備◎ |
| **S1** | 意志凝固 | 整備 UI：意志力2 | 高 | — |
| **C2** | 核接続 | C-2 契約 | タンク不要 | Nourishment |

**フロー**: 整備＝スタンドで缶を生成 → 各装置 UI「バッグからタンクへ」。相性一致で燃費 −15%、不一致 +10%（粗製のみでも可）。

**解放**: R1/R2/R3＝共通タブ 段階1〜3（`automationShopGradeCommon`）。S1＝整備 段階1 以降。

- 各装置: `harvestToolFuel` / `upkeepToolFuel` / `wardToolFuel`（初期40）＋ `*TankFuelRank`
- 燃料切れで `tickTool` 停止。**common_5 契約後**かつ `automationAutoWillRefuel` ON 時のみ、3秒クールダウン付きで意志をタンク補給（v8.5 調和比: 加重残滓100＝意志1、満タン≈意志2）
- 整備が `upkeepFuelRelay`（共通3）開放後、近傍の収穫・防衛へ燃料を中継（ランク引き継ぎ）
- **C-2 契約後**: 燃料タンク不要。微量の `currentWillpower` 消費（0.04/s、下限0.5維持）
- **燃費改善（共通4）**: 全装置 `runningCostPerSecond` ×0.9

実装: `lib/system/automation_fuel.dart`・`lib/system/automation_fuel_rank.dart`

## C-2 契約の段階解禁（共通6）

整備2または共通5購入後に**輪郭表示**（南京錠）。購入可になるまでの条件（すべて AND）:

| 条件 | 目安 |
| :--- | :--- |
| 収穫3・整備2・防衛1 購入済 | 装置別 grade |
| 3種装置を狩人から取得し設置済 | 戦闘・設置の骨格 |
| `automationKitStage >= 3` | 燃料サイクル運用 |
| `automationUpgradeStageTier >= 4` | outdoor_4 相当の調査 |
| `lastAlertHunterSpawnTier >= 2` | 高警戒の狩人と遭遇 |
| `farmCostWillpower >= 25` **または** 残滓コスト合計 `>= 100` | 自動化への累積支払い |

## 意志力自動補給（共通5・終盤）

| 条件 | 目安 |
| :--- | :--- |
| 共通4 購入済 | 燃費改善 |
| 収穫2・整備2・防衛2 | 3装置の中盤 |
| `automationUpgradeStageTier >= 3` | outdoor_3 相当 |

`automationAutoWillRefuel` デフォルト **false**。common_5 購入で `automationShopWillpowerAutoPay` が有効化。

未達時は `AutomationShopEntryStatus.locked` ＋ `Icons.lock` オーバーレイ。タップで次の一手を1件表示。

実装: `lib/system/automation_shop_unlock.dart`
